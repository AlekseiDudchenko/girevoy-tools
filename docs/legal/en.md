### Calculators and local workout storage

Calculations run in your browser. There is no Tools account or server-side workout
database. Workouts can contain a title, date, athlete and coach names, exercises,
loads and training entries. The workout builder stores sessions in this browser's
IndexedDB database `vsegiri-workouts`. The localStorage key `vsegiri-workout-last`
remembers the last selected workout.

These records are not uploaded to Tools by the workout feature. They remain until
you delete them using the available workout controls or clear this site's browser
storage; the browser may also remove them. There is no automatic expiry or cloud
backup. Clearing site storage removes locally saved workouts and the last-workout
selection. Downloaded backup files remain wherever you saved them.

### Sharing and external services

Workout sharing places the selected workout data in the link fragment after
`#data=`. This is encoding, not encryption. The fragment is not included in the
normal HTTP request to our hosting provider, but anyone who receives the complete
link can read the included data. Links may remain in messages, clipboard history,
browser history or browser synchronisation services. Tools has no central copy
that it can revoke. Exported files contain the data selected for export.

Registration and source links take you to third-party websites. Adding a calendar
subscription lets your chosen calendar provider retrieve the selected public
feed. If you use Google Calendar, Google receives the feed URL as part of that
action. Those services process data under their own privacy notices.
